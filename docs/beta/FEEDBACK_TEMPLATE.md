# Retour de bêta · Dakar Rek

Merci de tester ! Un retour = un problème ou une idée. Copie ce modèle dans ton message.

**1. Les infos du jeu** — dans le jeu : téléphone › Réglages › « Signaler un problème », puis colle ici ce qui a été copié
(la version du jeu, ton écran, l’endroit). Sinon, écris au moins la ligne « build » affichée en bas des Réglages.

```
(colle ici les infos copiées depuis le jeu)
```

**2. Ce que je faisais** — par exemple : « je conduisais la Teranga de Pikine vers le Plateau avec un client VTC ».

**3. Ce qui s’est passé** — ce que tu as vu ou entendu.

**4. Ce que j’attendais** — ce qui aurait dû se passer.

**5. Ça arrive** — ☐ à chaque fois ☐ parfois ☐ une seule fois

**6. Gravité** — ☐ je ne peux plus jouer ☐ gênant ☐ petit détail ☐ idée

**7. Une capture d’écran ou une courte vidéo** (très utile).

**Ton téléphone** — modèle (ex. iPhone 13, Samsung A54), navigateur (Safari, Chrome…), et si le jeu était fluide ou saccadé à cet endroit.

---
Rappel : ta partie est gardée **sur ce téléphone, dans ce navigateur**. Avant de vider le navigateur ou de changer de
téléphone : Réglages › Partie › « Copier ma sauvegarde », puis « Importer une sauvegarde » sur l’autre appareil.
L’argent du jeu n’a aucune valeur réelle.
